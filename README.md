# AiWebCity

Бесплатный городской проект для Новороссийска. На первом этапе пользователь загружает фотографию здания и адрес, а сервис пытается понять, что это за объект, ищет похожие изображения и исторические фотографии из открытых источников.

## Текущий этап MVP

`Фото здания + адрес + необязательный год`

→ анализ фасада через Timeweb AI Vision

→ формирование кандидатов на идентичность и поисковых запросов

→ геокодирование адреса

→ поиск изображений в Wikimedia Commons

→ поиск исторических фотографий рядом с координатами через PastVu API

→ ссылки на дополнительные открытые источники, включая PastPhoto

→ вывод источников пользователю

Генерация исторических изображений на этом этапе полностью отключена. Это сознательное решение: проект сначала должен научиться находить и сопоставлять реальные источники, а не создавать убедительную, но неподтверждённую историю.

## Источники

### PastVu

Используется официальный API PastVu: `https://api.pastvu.com/api2`, метод `photo.giveNearestPhotos`. По координатам можно задать радиус и верхнюю границу года, после чего сервис получает реальные исторические фотографии и ссылки на карточки снимков.

### Wikimedia Commons

Используется MediaWiki API Commons для поиска файлов по именам и описаниям, связанным с кандидатами и адресом. Wikimedia APIs предоставляют открытый доступ к данным и поиску проектов Wikimedia.

### PastPhoto

PastPhoto — дополнительный исторический фотоархив. В текущем MVP сервис даёт ссылку на страницу соответствующего места для проверки пользователем, но не строит критическую логику на хрупком HTML-скрейпинге.

### OpenStreetMap / Nominatim

Адрес преобразуется в координаты через Nominatim, чтобы можно было делать пространственный поиск исторических материалов. При дальнейшем росте нагрузки потребуется отдельная геокодирующая инфраструктура или согласованный провайдер.

## Бесплатность поиска

Платный Yandex Search API в первый MVP не входит. Это сделано намеренно, потому что сервис для жителей должен работать без зависимости от тарифа обратного поиска изображений. Позже можно добавить коммерческий reverse-image provider как необязательный ускоритель, но ядро системы не должно на него опираться.

## Переменные окружения

```env
TIMEWEB_AI_TOKEN=ваш_ключ
TIMEWEB_API_BASE=https://api.timeweb.ai/v1
TIMEWEB_VISION_MODEL=openai/gpt-4.1-mini
MAX_UPLOAD_MB=12
```

## Запуск

```bash
git clone https://github.com/ruslanforeks/AiWebCity.git
cd AiWebCity
cp .env.example .env
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://SERVER_IP:8000`.

## Безопасность исторических данных

Vision-модель должна отделять видимые признаки от предположений и не выдавать даты, архитекторов, старые названия и другие исторические утверждения без источника. UI использует качественный статус совпадения (`высокая / средняя / низкая`), а не выдуманный процент.

Также сервис не считает сам факт наличия фотографии рядом с адресом доказательством того, что на ней изображено то же здание. Финальная идентификация должна опираться на совокупность признаков: адрес, география, архитектурный отпечаток, совпадающие детали фасада и независимые источники.

## Следующий этап

После накопления реальных результатов поиска можно добавить локальный индекс фотографий Новороссийска, image embeddings, reranking кандидатов и отдельный модуль оценки визуального совпадения. И только после проверки этой части возвращаться к исторической реконструкции.
