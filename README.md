# AiWebCity

Бесплатный городской проект для Новороссийска. На первом этапе пользователь загружает фотографию здания и адрес, а сервис пытается понять, что это за объект, ищет похожие изображения и исторические фотографии из открытых источников.

## Текущий этап MVP

`Фото здания + адрес + необязательный год`

→ анализ фасада через Timeweb AI Vision

→ формирование кандидатов на идентичность и поисковых запросов

→ геокодирование адреса

→ поиск визуальных совпадений через Yandex Search API (опционально)

→ поиск изображений и категорий в Wikimedia Commons

→ поиск исторических фотографий рядом с координатами через PastVu API

→ ссылки на дополнительные открытые источники, включая PastPhoto

→ вывод источников пользователю

Генерация исторических изображений на этом этапе полностью отключена. Это сознательное решение: проект сначала должен научиться находить и сопоставлять реальные источники, а не создавать убедительную, но неподтверждённую историю.

## Источники

### Yandex Search API

Yandex Search API поддерживает поиск изображений по заданной фотографии и возвращает JSON с URL изображения, страницей-источником, заголовком и фрагментом текста. Для обратного поиска проект использует `POST https://searchapi.api.cloud.yandex.net/v2/image/search_by_image` с API-ключом и `folderId`. Если параметры Yandex не заданы, основной поиск продолжает работать без него.

### PastVu

Используется официальный API PastVu: `https://api.pastvu.com/api2`, метод `photo.giveNearestPhotos`. Для координат можно задать радиус и верхнюю границу года, после чего сервис получает реальные исторические фотографии и ссылки на карточки снимков.

### Wikimedia Commons

Используется MediaWiki API Commons для поиска файлов по именам и описаниям, связанным с найденными кандидатами и адресом.

### PastPhoto

PastPhoto — интерактивный исторический фотоархив, использующий сторонние публичные API. В текущем MVP ссылка на соответствующее место показывается как дополнительный источник для ручной проверки. Прямую критическую логику сервиса на хрупком HTML сайта не завязываем.

## Переменные окружения

```env
TIMEWEB_AI_TOKEN=ваш_ключ
TIMEWEB_API_BASE=https://api.timeweb.ai/v1
TIMEWEB_VISION_MODEL=openai/gpt-4.1-mini

# Опционально для обратного поиска по фото через Yandex Search API
YANDEX_API_KEY=
YANDEX_FOLDER_ID=

MAX_UPLOAD_MB=12
```

## Запуск

```bash
git clone https://github.com/ruslanforeks/AiWebCity.git
cd AiWebCity
cp .env.example .env
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://SERVER_IP:8000`.

## Безопасность исторических данных

В ответе Vision-модели запрещены исторические утверждения без источников. UI показывает вероятность совпадения как качественный статус (`высокая / средняя / низкая`), а не как научно необоснованный процент.

Также сервис не воспринимает само наличие фотографии рядом с адресом как доказательство того, что это именно тот же объект. Финальная идентификация должна опираться на совокупность признаков: адрес, география, архитектурный отпечаток, совпадающие детали фасада и независимые источники.

## Следующий этап

После накопления реальных результатов поиска можно добавить локальный индекс фотографий Новороссийска, image embeddings и reranking нескольких кандидатов. И только после проверки этой части возвращаться к исторической реконструкции.
