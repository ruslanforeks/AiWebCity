# AiWebCity

Бесплатный городской проект для Новороссийска. На первом этапе пользователь загружает фотографию здания и адрес, а сервис пытается понять, что это за объект, ищет визуальные совпадения и исторические фотографии.

## Текущий MVP

`Фото здания + адрес + необязательный год`

→ анализ фасада через Timeweb AI Vision

→ формирование кандидатов на идентичность и поисковых запросов

→ геокодирование адреса

→ поиск визуальных совпадений в Wikimedia Commons

→ поиск исторических фотографий рядом с координатами через PastVu API

→ дополнительная ссылка на PastPhoto

→ по желанию — обратный поиск по загруженной фотографии через официальный Yandex Search API

Генерация исторических изображений на этом этапе полностью отключена. Сначала сервис должен научиться находить реальные источники и сопоставлять объект.

## Yandex reverse-image search

В проект добавлен отдельный адаптер для Yandex Search API. Он **выключен по умолчанию**.

Чтобы включить его для тестирования, в `.env` нужно явно задать:

```env
YANDEX_IMAGE_SEARCH_ENABLED=true
YANDEX_API_KEY=ваш_ключ
YANDEX_FOLDER_ID=ваш_folder_id
```

После включения результаты обратного поиска попадут в отдельный блок «Поиск по фото в Яндекс Картинках». Пока переключатель `false`, приложение не обращается к Yandex Search API.

Это коммерческий/тарифицируемый компонент Yandex Cloud, поэтому для бесплатного городского ядра мы не делаем его обязательным. По официальной документации Yandex Search API поддерживает поиск изображений по изображению и имеет отдельные квоты для image-by-image search.

## Открытые источники

### PastVu

Используется официальный API PastVu: `https://api.pastvu.com/api2`, метод `photo.giveNearestPhotos`. По координатам можно искать реальные исторические фотографии в заданном радиусе и ограничивать верхнюю границу года.

### Wikimedia Commons

Используется MediaWiki API Commons для поиска файлов по названиям, описаниям и поисковым запросам, сгенерированным модулем идентификации.

### PastPhoto

PastPhoto используется как дополнительный исторический фотоархив. В текущем MVP пользователь получает ссылку на соответствующую страницу места для ручной проверки. Критическая логика не зависит от хрупкого HTML-скрейпинга.

### OpenStreetMap / Nominatim

Используется для преобразования адреса в координаты и последующего пространственного поиска исторических материалов. При высокой нагрузке потребуется отдельная геокодирующая инфраструктура.

## Yandex Maps: что может пригодиться дальше

У Yandex Maps API есть отдельные продукты для геокодирования, подсказок адресов и поиска организаций. Places/Organization Search позволяет искать организации по названию, адресу и другим параметрам и возвращает геоданные и метаданные найденного объекта. Это потенциально полезно для следующего этапа, когда понадобится сопоставлять адрес здания с современными организациями в нём.

Для текущего бесплатного MVP эти платные API не являются обязательными. Для интерфейса карты можно использовать бесплатный вариант JavaScript API с учётом его условий использования.

## Переменные окружения

```env
TIMEWEB_AI_TOKEN=ваш_ключ
TIMEWEB_API_BASE=https://api.timeweb.ai/v1
TIMEWEB_VISION_MODEL=openai/gpt-4.1-mini

# Опционально: платный reverse-image search через Yandex Search API
YANDEX_IMAGE_SEARCH_ENABLED=false
YANDEX_API_KEY=
YANDEX_FOLDER_ID=

MAX_UPLOAD_MB=12
```

## Запуск

```bash
git clone https://github.com/ruslanforeks/AiWebCity.git
cd AiWebCity
cp .env.example .env
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://SERVER_IP:8000`.

## Принцип достоверности

Vision-модель должна отделять видимые признаки от предположений и не выдавать исторические сведения без источника. Финальная идентификация должна опираться на совокупность независимых признаков: адрес, география, архитектурный отпечаток, совпадающие детали фасада и найденные источники.

## Следующий этап

После накопления реальных результатов поиска можно добавить локальный индекс фотографий Новороссийска, image embeddings и reranking кандидатов. Это позволит строить собственный визуальный поиск и со временем уменьшить зависимость от внешних коммерческих reverse-image сервисов. Только после проверки идентификации возвращаемся к исторической реконструкции.
