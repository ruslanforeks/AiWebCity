# AiWebCity

Бесплатный городской проект для Новороссийска: пользователь фотографирует здание, указывает адрес и исторический период, после чего сервис анализирует современный объект и использует архивные изображения как доказательства для визуальной реконструкции.

## Что есть в MVP

- FastAPI backend + простой адаптивный frontend.
- Анализ современной фотографии через Timeweb AI Gateway.
- Локальный архив без платного vector/embedding API.
- `data/archive.json` — лёгкий манифест архивных изображений и их источников.
- Жёсткое правило evidence-first: без архивных изображений реконструкция не создаётся.
- Попытка генерации через выбранную image-модель Timeweb.
- Результаты сохраняются локально в `data/results`.
- Dockerfile для запуска на VPS/App Platform.

## Быстрый запуск

```bash
git clone https://github.com/ruslanforeks/AiWebCity.git
cd AiWebCity
cp .env.example .env
# Вставьте токен в TIMEWEB_AI_TOKEN
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://SERVER_IP:8000`.

## Timeweb

Базовый URL по умолчанию: `https://api.timeweb.ai/v1`.

В `.env` нужно указать:

```env
TIMEWEB_AI_TOKEN=ваш_ключ
TIMEWEB_VISION_MODEL=openai/gpt-4.1-mini
TIMEWEB_IMAGE_MODEL=openai/gpt-image-2
```

**Важно:** точные идентификаторы моделей зависят от списка моделей, доступного в вашем Timeweb AI Gateway. Скопируйте их из раздела «Подключение» и при необходимости замените значения в `.env`.

## Архив

Сначала положите исторические фотографии в `data/archive/`. Для каждого изображения желательно заполнить `data/archive.json`:

```json
[
  {
    "path": "sovetov_15_1913.jpg",
    "year": 1913,
    "address": "Новороссийск, ул. Советов, 15",
    "description": "Главный фасад, вид с улицы",
    "source": "Название архива или ссылка на источник"
  }
]
```

Для быстрого создания пустого манифеста из имеющихся файлов:

```bash
python tools/build_archive_manifest.py
```

После этого рекомендуется вручную добавить год, адрес и источник. Это не карточки зданий: это метаданные самих исторических изображений.

## Архитектура

`Фото пользователя + адрес + год`

→ AI-анализ современного здания

→ отбор локальных архивных кандидатов

→ передача современного фото + архивных доказательств генератору

→ сохранение реконструкции

В первой версии намеренно нет 3D, тяжёлой vector DB и платных embedding-запросов. Эти компоненты можно добавить после проверки качества на реальных зданиях Новороссийска.

## Ограничение MVP

Timeweb публикует поддержку генерации изображений для AI-агентов, а список поддерживаемых API и конкретные возможности зависят от используемой модели. Поэтому адаптер генерации сделан отдельным и возвращает понятную ошибку, если конкретный image-model ID или формат ответа недоступен через выбранный API.

Проект бесплатный для пользователей. Все AI-запросы оплачиваются владельцем инфраструктуры.
