Что это за здание?

Фото → реальные визуальные совпадения → проверка адреса → исторические фотографии. Только Новороссийск.

Введённый адрес заметно повышает точность: сервис ищет фотографии по этому адресу и сверяет их с вашим снимком.
Адрес не считается правильным автоматически. Сначала сервис ищет совпадение здания по фотографиям, и только потом проверяет адрес найденного кандидата.
Фото не сохраняется на VPS. Оно временно используется внешним поиском и AI.
